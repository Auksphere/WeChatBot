# WeChatBot · 微信角色机器人管理台

为 **AstrBot + WeChat Native + DeepSeek** 提供本地网页管理界面。双击桌面快捷方式打开，机器人停止后管理台仍然可用。


## 功能

- 独立启动、停止、重启机器人，查看微信登录状态。
- 微信扫码登录、群目录同步、按群名搜索并接入或移除群聊。
- 编辑固定角色，配置 DeepSeek 模型与密钥，开关私聊直接回复。
- 查看待处理好友申请，按账号开启或关闭自动通过；成为好友后沿用私聊回复规则。
- 可选 Stella 女声、Tide 男声或哈基米（Fish Audio 社区音色），支持本页试听。
- 表情候选预览、同步手机已添加的表情、自动浏览并获取微信免费表情包、设置自动配表情频率。
- 按真实微信 ID 查看、编辑、清除或重新开启长期记忆；支持逐项修改与删除，保存后下次聊天生效。
- 查看经过常见密钥及音频数据脱敏的运行日志。
- 群聊与私聊共用角色和个人档案，聊天历史按会话分别保存。
- 私聊默认过滤微信团队等内置系统账号，以及接口已确认的官方/服务账号；按账号身份判断，不按昵称。群成员转发公众号文章仍可读取。
- 随附定制插件源码：链接与搜索、图片与引用表情、语音、视频号卡片读取、文档和视频抽样、同群近期公开讨论、按请求选择思考强度。

## 当前适用范围

第一版支持**绑定已有的 Windows 机器人部署**。管理台不捆绑 Python 环境、AstrBot、微信登录态或 Native 二进制，也不是完整的首次微信部署安装器。当前管理一个 `wechat-rolebot` 实例和“大肥鱼”角色。

已验证的组合：Windows、Python 3.12、AstrBot 4.29.4、WeChat Native 插件 0.3.21、agent-wechat 2.9.0。现有部署应符合 [部署目录说明](docs/DEPLOYMENT.md)。

## 开始使用

建议将运行环境统一放在项目的 `.runtime/` 下：机器人数据在 `.runtime/bot/`，基础 Python 在 `.runtime/python/`；这些目录已忽略，不会作为源码发布。

在 PowerShell 中运行：

```powershell
.\setup.ps1 -DeploymentRoot 'D:\your-bot-deployment'
```

然后双击桌面的 **大肥鱼管理台**。也可以双击 `start.cmd`，或从部署的 Python 运行：

```powershell
D:\your-bot-deployment\.venv\Scripts\python.exe .\launch.py --root 'D:\your-bot-deployment'
```

管理台固定监听 `http://127.0.0.1:6186`，高级后台为 `http://127.0.0.1:6185`。首次打开请通过启动器获取本机授权；直接输入地址但尚无管理会话时，会提示从快捷方式打开。

`setup.ps1` 只绑定目录并创建快捷方式，不替换现有机器人配置和插件。插件和运行脚本的更新应先备份，再按 [部署目录说明](docs/DEPLOYMENT.md) 操作。

## 页面

| 页面 | 用途 |
| --- | --- |
| 运行概览 | 服务状态、启停、常用入口、管理操作结果 |
| 微信连接 | 微信状态、生成登录二维码、扫码确认 |
| 群聊与私聊 | 同步目录、搜索群名、接入与移除 |
| 角色设定 | 修改当前微信号绑定的人设 |
| 模型与能力 | 模型、API Key、私聊开关、语音音色与试听 |
| 表情库 | 预览自动表情候选、同步、调整频率 |
| 个人记忆 | 查看成员档案、清除并停止记录、重新开启 |
| 日志与诊断 | 机器人、错误、微信服务启动日志 |

模型、角色和群设置在机器人运行时保存，会短暂重启；停止时保存则在下次启动生效。管理台本身持续运行。修改配置前会备份到部署目录的 `data/config-backups/`。

## 添加新群

先把**机器人微信号**加入目标群，在群里发一条普通文字消息，再进入“群聊与私聊”点击“同步并发现新群”，找到目标群后点击“接入群聊”。群聊页右上角刷新也会执行同步；浏览器 F5 只重新读取本地目录。

同步会检查联系人、群资料和群会话，群资料尚未建立但已有会话的新群也会显示。微信群资料接口可能只返回部分目录，管理台会提示覆盖范围和本次发现数量；“同步任务结束”不代表微信已提供全部群。新群不会自动加入回复名单。

## 可选哈基米音色

在“模型与能力 → 语音音色”选择“哈基米（曼波）”，填写独立的 [Fish Audio API Key](https://fish.audio/app/developers/get-started/)，先生成试听，再保存并应用。默认声音保留 Stella；启用哈基米后，需要朗读的回复文字会交给 Fish Audio 合成，语音识别仍使用 DeepSeek。

预填社区音色 ID `ae5adc6778ac459e8d6106b82f88fa2b`，可在 [音色页面](https://fish.audio/zh-CN/m/ae5adc6778ac459e8d6106b82f88fa2b/) 听样本，也可填入其他 Fish 音色 ID。声音质量、音色可用性以实际试听为准。默认 `s2.1-pro-free` 免费档，另可选择需 API 余额的 `s2.1-pro`；模型及计费见 [官方文档](https://docs.fish.audio/developer-guide/models-pricing/choosing-a-model)。

试听不保存设置、不发微信，音频只在内存中生成并在浏览器播放。密钥只保存于已忽略的运行配置，不返回页面；密钥输入留空保留旧值。群聊和私聊沿用当前微信号绑定的音色，合成失败保留文字回答；接口等待和音频大小有限制。

源码提供 API 接入，不包含第三方音色音频或模型权重。更新已有部署时，同时更新定制插件的 `speech.py` 和 `tts.py`，再重启机器人。

## 自动获取免费表情包

在“表情库”开启“自动获取免费表情包”并保存。机器人在线且微信已登录时，后台每 6 小时浏览接口可见的微信表情包目录，每批最多新增 2 个包，累计最多 6 个包、120 个新候选。也可点击“立即更新免费表情包”，稍后刷新查看获取、下载和识别进度。

仅添加接口确认符合免费资格的表情包；目录并非微信客户端的全局关键词搜索。下载后使用已配置的模型识别真实预览图、生成内容描述，再纳入原有的语境选表情流程。识别会使用现有模型 API 配额；每轮最多识别 24 张。只有可校验的本地 GIF 才进入候选，发送前再次核对成员关系与内容。不会在下载过程中向微信发送进度消息。

关闭自动获取可停止后续获取，已下载的候选仍可按语境使用；关闭“聊天中自动配表情”则停止自动发送。手机手动移除的自动表情包不会被重新添加。手机同步候选保持原样，与自动获取候选合并显示。获取任务的原幂等键、回执和进度只保存在被忽略的私有运行目录，重启后继续核对，结果未确认时不会换新键重复提交。

## 自动通过好友申请

在侧栏“好友申请”查看当前申请，默认开启自动通过。可关闭后逐条点击“通过申请”，失败申请可显式“重试通过”；手动请求进入同一操作队列，约 30 秒后刷新查看结果。自动模式处理当前待处理和后续有效的收到申请，机器人在线时约每 30 秒检查一次；只使用账号已有的 Native 管理凭据，不需要把好友管理工具开放给聊天模型。

每次操作都会重新读取申请并核对版本，跳过已经是好友、过期或不可操作的申请。操作记录保存在私有运行目录，程序重启或网络超时后继续核对原回执，不换新键盲目重试。申请人的名字和验证消息只作为显示资料，不参与执行逻辑。

微信最终拒绝时显示失败，不能保证每条申请都能通过。自动通过不会主动发招呼消息，也不会自动通过入群邀请。新好友的回复仍取决于私聊开关及允许用户列表；可通过允许用户列表限制私聊范围。关闭机器人后不会自动处理。

## 读取视频号

群里先转发视频号卡片，再引用该卡片并原生 @ 或手打 `@大肥鱼 总结这个视频`。私聊可以直接转发卡片；未引用时也可在 10 分钟内追问自己最近转发的视频号。读取其他群成员转发的内容时，请准确引用目标卡片。

下载通过现有的 agent-wechat 身份验证接口进行，使用视频号 `normal` 视频资产，不把卡片封面当作视频。单个视频最大 100 MiB、4 小时；按完整时间轴分段，每段最多约两分钟，边界音频约重叠 1 秒，每段全程均匀抽取最多 6 幅画面。各段分别转写音频、分析画面，再汇总全片；分段笔记过长时分层合并，结尾不会被直接截断。音频、画面或分段分析失败会标出缺失时间区间。资料交给当前配置的模型，发布者、转发者和提问者保持区分。

短视频保留直接图像输入；长视频先提炼各段证据，再由主模型按当前问题汇总（包括中后段与结尾）。普通视频附件使用相同流程，私聊可直接发视频，群里引用视频并 @ 提问。处理完成后直接输出分析结果，不发送下载、分段或汇总中的进度提示；片长、内容复杂度和 API 响应决定耗时与费用。

视频号可能已删除、私密、过期或暂时无法下载，失败会直接说明，不承诺稍后补发。若使用 Clash 等代理的 Fake IP DNS，需使 `finder.video.qq.com` 返回真实公网 IP；接入层的公网地址校验保留，不接受虚拟或内网地址。视频号图文、多视频合集、直播以及独立搜索、评论和发布不在本版范围。

## 开发与检查

管理台后端使用 Python 标准库，前端为原生 HTML/CSS/JavaScript，无 Node 构建步骤。表情缩略图和已有运行脚本依赖部署环境中的 Pillow、psutil 以及插件依赖。

```powershell
python -m unittest discover -s tests -v
node --check manager_app/static/app.js
python tools/check_source.py
```

测试使用临时虚构部署，不连接微信，不发送任何聊天消息，不修改真实个人档案。

## 项目结构

```text
manager_app/       本地服务、管理接口、静态网页

setup.ps1          绑定已有部署、创建桌面快捷方式
launch.py          独立管理服务启动器
```

项目自身代码采用 MIT；随附第三方源码保留原始许可证。依赖及本地改动见 [第三方说明](THIRD_PARTY_NOTICES.md)。


私聊表情：好友直接发送微信表情包即可触发读取和自然回复，无需再引用或补一条文字；群聊仍需引用后 @。明确的“发一个表情包／发一个得意的表情包”由专用流程处理，正常聊天可按语境配表情。模型误输出的内部工具标记会被过滤，不作为指令执行，也不进入微信正文。

## 上下文与用法示例

本群公开讨论参考最近 24 小时、最多 200 条消息，正文总计最多约 24000 字符；私聊参考最近 7 天、最多 100 条双方消息，正文总计最多约 32000 字符。优先保留较新的内容，每条标注发送者，仍按账号和会话隔离，并遵守忘记资料后的历史补充边界。只读历史文字和链接不会重新解析旧附件。

当前部署将 `agent_runner.config.compression.max_turns` 从 20 调整为 100，`trim_turns` 从 5 调整为 10；超出模型输入容量时仍由框架裁剪。群聊和私聊的普通模型对话都采用该轮数设置。Native 历史补充只在本次请求临时使用，不复制成另一会话的永久历史。

群里或私聊直接发送 `/用法`，可获取带具体例子的指南，覆盖多人讨论续聊、私聊追问、个人记忆、截图、表情、文档、视频号、搜索、文章总结和语音。

模型异常恢复：模型把内部工具调用写成正文时，系统会在当前消息内自动尝试一次无工具的答案重生成。需要实时事实时只按当前提问走已有的只读检索，不执行异常文本中的工具参数。仍失败时给出明确失败说明或已有来源，并停止自动配表情；历史错误占位文本不再回送模型。

## Bilibili 与小红书视频

群里直接发 `@大肥鱼 总结这个视频，包含结尾：<分享链接>`，或转发平台卡片后引用并 @ 提问；私聊可直接发分享卡片或链接，也可在本人分享后 10 分钟内追问。读取其他成员分享的视频需要精确引用。支持 b23.tv、B站常规视频页、小红书视频笔记及分享短链接，保留小红书分享校验参数，并规范化 B站语言前缀。B站默认当前分P，不自动下载整个合集或直播。

下载后复用现有全片音频分段转写、全程抽帧与汇总，不把标题和封面当视频内容。只输出最终分析，保留来源链接和缺失区间。最多 100MiB、4小时；尽量选择较低画质，超限、图文笔记、登录/验证限制或失效时明确说明，可保存为普通视频再发。

使用固定版本 yt-dlp 进行匿名解析，不读取浏览器 Cookie 或账号登录态；仅允许平台及其 CDN 的 HTTP(S) 请求，重定向也会检查。下载工作进程最多 180 秒，临时文件位于 D 盘项目私有运行目录；消息撤回和来源改变会停止处理，并在发送前再次核对。

视频回复直接给内容、观点、结论和原链接，默认不汇报时长、分段数、抽帧数或覆盖过程；用户主动问处理统计时才回答。内容中的时间戳、原视频帧率和实际缺失说明仍保留。平台暂时未返回视频流、网络超时等错误会在原 180 秒预算内重新获取一次；登录限制、无效链接、超出大小/时长等错误不重复请求。
