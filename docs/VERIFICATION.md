JavaScript 语法检查和源码发布检查通过。测试使用虚构身份和临时数据，不需要微信登录，也不发送真实聊天消息。

## 真实接口验证范围

已在本地部署验证微信连接与管理接口、媒体读取、语音、视频分析、免费表情包下载与内容识别。使用虚构庆祝对话验证了语境选择器能挑选新下载的表情，未发送主动测试消息。部分表情包可能返回不支持的媒体格式，流程会跳过，已有候选仍可用。

真实验证与离线检查相互补充，不能保证所有微信账号、所有表情包或第三方平台内容均可访问。模型 API 的可用性、媒体权限、平台限制和源消息状态会影响结果。

## 发布验证边界

本仓库不含运行配置、密钥、登录态、聊天记录、个人记忆、媒体缓存或真实用户标识。运行截图和包含具体会话细节的历史诊断记录不在发布内容中。

GitHub Actions 已提供依赖安装和检查流程；远程运行结果以目标仓库 Actions 页面为准。当前版本用于绑定已有 Windows 部署，不是完整的首次安装器。
